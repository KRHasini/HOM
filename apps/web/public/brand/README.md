# Brand files

Drop the supplied logo files here. Until they exist the site renders a coded "HOM"
wordmark (and the build prints a warning listing what is missing).

| File | Used for |
| --- | --- |
| `logo-white.svg` | Header, footer, menus (on dark) |
| `logo-black.svg` | Light surfaces |
| `mark.svg` | Compact mark (leaping dancer inside the "O") |
| `og-default.jpg` | Social share image, 1200×630 (a generated card is used until then) |

The favicon is `src/app/icon.svg`; replace it with the studio mark if preferred.
